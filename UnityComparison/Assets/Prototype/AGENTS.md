# Interior changes

For edits to room layouts, furniture, indoor characters or cutaway interiors, read `D:/Bite-Tycoon/docs/INTERIOR_LAYOUT.md` first and follow its measurement and visual-verification workflow. Keep the rendered room type consistent with the player's saved choice. Fix asset orientation before compensating with placement offsets.

The active game project is `UnityComparison`. Validate the actual imported meshes and browser output; compilation alone does not verify furniture placement.
