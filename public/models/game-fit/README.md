# Local city-fit prototype assets

The prototype uses downloaded model files only for local visual review; they are excluded from Git. These files are not part of the live game's scene.

## Downtown Toronto

"Downtown Toronto (Yonge and Dundas)" by **Daniel Boxer**

https://sketchfab.com/3d-models/downtown-toronto-yonge-and-dundas-a867077e68b8443297d682bf4a21a1af

Listed license: **Creative Commons Attribution 4.0**, https://creativecommons.org/licenses/by/4.0/ . Attribution is displayed in the prototype. Toronto currently uses the official online viewer: the authenticated GLB and glTF downloads returned HTTP 403. No local Toronto asset or mapped tenancies are included. Business uses are hypothetical, not statements about real building occupants.

The interiors, business names, management interface and simulation come from Bite Tycoon, not from these downloaded exterior models. Prototype saves use their own key, `bite_tycoon_city_fit_prototype_v1`.
